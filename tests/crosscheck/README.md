# tests/crosscheck/

Comparisons with published tables and fetched extracts: the Indian
Astronomical Ephemeris's ayanāṃśa polynomial and the fetched IERS and
Hipparcos extracts. Each tolerance is stated with its reason. No
comparison with independent software is in the 1.0.0 suite, and the
optional `extras` tier holds no test
([`docs/installation.md`](../../docs/installation.md)).
