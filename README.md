# jyotirganita
A deterministic, fully parameterized pañcāṅgam computation engine for the scientific study of Indian calendrical traditions — historical almanacs, inscriptions, and siddhantic astronomy.

## Status: placeholder release

Version `0.0.1` is a **name reservation** and contains no functionality. Importing
the package succeeds and reports its version; accessing anything else raises an
explanatory error.

The computation engine is under active development. The first functional public
release will be version `1.0.0`, expected in a few months. Until then, please do
not depend on this package.

Project home and issue tracker: <https://github.com/thomas-mathew-lab/jyotirganita>
